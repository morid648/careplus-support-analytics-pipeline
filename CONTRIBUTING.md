# Contributing

This is a personal portfolio project built to demonstrate individual, hands-on data engineering skills, so it isn't set up as an actively-maintained open-source project seeking external contributions.

That said, feedback is welcome:

- **Found an issue or have a suggestion?** Feel free to open a GitHub Issue describing it.
- **Want to discuss the architecture or approach?** Open a Discussion or reach out directly — see contact details on the profile associated with this repository.

If you'd like to fork this project and extend it (e.g. adding Airflow orchestration, Terraform IaC, or CI/CD, as noted under [Future Enhancements](README.md#status--future-enhancements)), please feel free — attribution back to this repository is appreciated but not required.

Please do not open issues or PRs requesting the original course dataset — it is intentionally excluded from this repository (see [`sample-data/README.md`](sample-data/README.md)).
